Test from another machine / the internet

Prove external reachability (what a cellular tracker needs) with the standalone probe — Python 3 only, no install:

python tools/fmc_probe.py {{ FLEET.PUBLIC_GPS_HOST }} {{ FLEET.PUBLIC_GPS_PORT }} --imei {{ FLEET.SELFTEST_IMEI }}

Windows PowerShell port check:

Test-NetConnection -ComputerName {{ FLEET.PUBLIC_GPS_HOST }} -Port {{ FLEET.PUBLIC_GPS_PORT }}

Continuous simulated vehicle:

python manage.py simulate_device --host {{ FLEET.SELFTEST_HOST }} --port {{ FLEET.SELFTEST_PORT }} --imei {{ FLEET.SELFTEST_IMEI }} --interval 5

A local port check cannot prove cellular reachability. Test from a different internet connection (e.g. phone hotspot). HTTP-only tunnels cannot carry the binary protocol.
